# Protótipo de Site de Marketing - Comali

Este diretório contém um protótipo isolado do site de marketing, totalmente independente do site principal.

## Estrutura

- `calculadora-economia-secadores/`: Versão funcional da calculadora
- `guia-escolha-lixeira/`: Página completa do guia com formulário de download
- `comali-vs-concorrente/`: Página de comparação pronta para visualização
- `onboarding-emails/`: Exemplo de email 1 da sequência

## Como Visualizar

1. Navegue até a pasta desejada
2. Execute `npm run dev` dentro dela (se for um projeto Next.js)
3. Acesse `http://localhost:3000` no navegador

> **Nota:** Este protótipo é autocontido e não afeta o site atual em produção.
